# Bubble Sort — TDD

**Dupla:** Matheus Goulart de Alencar e Miguel Falcão Costacurta.

Projeto Maven com Java 17 e JUnit 5.

O método `ordenar()` aplica o Bubble Sort em ordem crescente. Os três testes fornecidos verificam vetores desordenados, já ordenados e com valores repetidos.

## Executar

```bash
mvn clean verify
```

O relatório de cobertura é gerado em `target/site/jacoco/index.html`.
