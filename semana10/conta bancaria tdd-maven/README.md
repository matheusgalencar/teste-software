# Conta Bancária — TDD

**Dupla:** Matheus Goulart de Alencar e Miguel Falcão Costacurta.

Projeto Maven com Java 17 e JUnit 5.

## Executar

```bash
mvn clean verify
```

## Prática

Os quatro testes fornecidos verificam depósito, acúmulo de depósitos, saque e preservação do saldo quando o saque excede o valor disponível.

O relatório de cobertura é gerado em `target/site/jacoco/index.html`.
