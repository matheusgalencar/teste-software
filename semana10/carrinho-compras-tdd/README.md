# Carrinho de Compras — TDD

**Dupla:** Matheus Goulart de Alencar e Miguel Falcão Costacurta.

Projeto Maven para prática de TDD com Java 17 e JUnit 5.

## Executar os testes

```bash
mvn test
```

## Atividade

Leia `REQUISITOS.md` e implemente os requisitos sequencialmente.

No projeto-base, os testes não eram fornecidos prontos. Nesta entrega, os requisitos foram convertidos em testes e implementados. Para preço negativo, foi adotada a exceção `IllegalArgumentException`.
